# MeetUp - Video Conference App

MeetUp is a powerful video conferencing app that allows users to conduct online meetings, webinars, and classes effortlessly. Built with Flutter, it supports Android, iOS, and web platforms, offering high-quality video and audio conferencing with encryption by default.

## Features

- **Instant Video Conferencing**: Supports an unlimited number of users.
- **Cross-Platform**: Available on Android, iOS, and web.
- **No Login Required for Joining**: Users can join meetings with just a meeting code.
- **Live Streaming**: Includes features like live streaming to YouTube.
- **Chat and Meeting History**: Offers in-meeting chat and access to past meetings.
- **Security**: Lock-protected rooms with passwords.
- **Multi-Language Support**: Available in Arabic, English, French, Spanish, German, and Korean.
- **Record Meetings**: Ability to record sessions for later review.

## Installation

Follow the detailed documentation provided to set up the app. Ensure the server meets the following requirements:
- PHP >= 8.1
- MySQL >= 5.6
- Required PHP extensions: OpenSSL, PDO, Mbstring, CURL, Fileinfo
